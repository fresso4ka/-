# Трекер личных расходов

Учебный проект на Python: Flask, REST API, SQLite и Tkinter.

## Возможности
- добавление расхода (сумма, категория, дата, комментарий);
- просмотр истории расходов;
- удаление записей;
- подсчёт общей суммы;
- REST API для получения, добавления и удаления расходов;
- отдельное оконное приложение на Tkinter.

## Запуск веб-версии
1. Установите Python 3.10 или новее.
2. Откройте терминал в папке проекта.
3. Установите зависимости:
   `python -m pip install -r requirements.txt`
4. Запустите:
   `python app.py`
5. Откройте в браузере адрес `http://127.0.0.1:5000`.

База данных `expenses.db` создаётся автоматически при первом запуске.

## Запуск оконной версии
В отдельном терминале выполните:
`python desktop.py`

Tkinter обычно входит в стандартную поставку Python. В некоторых Linux-системах его нужно установить отдельно.

## API
### Получить все расходы
`GET /api/expenses`

### Добавить расход
`POST /api/expenses` с JSON-телом:
```json
{
  "amount": 450.50,
  "category": "Продукты",
  "date": "2026-07-02",
  "comment": "Покупки на неделю"
}
```

### Удалить расход
`DELETE /api/expenses/1`

### Получить общую сумму
`GET /api/total`

## Проверка в Postman
Для добавления выберите POST, URL `http://127.0.0.1:5000/api/expenses`, Body → raw → JSON.
Для просмотра используйте GET `http://127.0.0.1:5000/api/expenses`.
Для удаления используйте DELETE `http://127.0.0.1:5000/api/expenses/1`.

## Структура
- `app.py` — веб-приложение и API;
- `database.py` — функции для работы с SQLite;
- `templates/index.html` — HTML-страница;
- `static/style.css` — оформление;
- `desktop.py` — оконная версия;
- `requirements.txt` — зависимость Flask.
